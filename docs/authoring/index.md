# 스킬 만들어 올리기

스킬 저자가 카탈로그 저장소에 스킬을 올리고, 고치고, 은퇴시키는 법입니다.

## 전제 조건

- 카탈로그 저장소의 로컬 clone과 write 권한(브랜치·PR).
- `uv`(스크립트 실행과 CLI 설치), `gitleaks`(검사 항목 4가 필요로 함), `git`·`gh`.
- evals를 돌리려면 `harbor`(0.24.0)와 Docker, 하네스의 모델 자격, Langfuse 키.
- 하네스에서 `write`를 [적재](../using/find.md)하면 아래 절차를 에이전트가 대신 밟습니다. 올린 뒤 발동이 안 되거나 다듬고 싶을 때는 `review` 스킬이 저작 지침(agentskills 스펙·Anthropic·Codex)과 팀 규약의 점검표로 심사해 표를 내고, 고른 항목을 브랜치에 고칩니다. 첫 단계는 절차를 판단과 결정적 부분으로 가르는 것입니다 — 판단은 본문으로, 결정적 부분은 도구로(있으면 이름으로 엮고 없으면 새로). 손으로 해도 같습니다.
