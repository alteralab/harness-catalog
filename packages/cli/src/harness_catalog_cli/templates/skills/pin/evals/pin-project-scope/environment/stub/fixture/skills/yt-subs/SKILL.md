# yt-subs

## 언제 쓰는가

- 쓴다: "자막 뽑아줘", "유튜브 자막 추출해줘".
- 쓰지 않는다: 영상 요약.

## 단계

1. URL을 확인한다.
2. 도구 `subs-fetch`를 `{"url": …}`로 부른다. 결과: `text`
3. 사람 승인 전까지는 되돌릴 수 있는 일만 한다.

## 실패 대응

| 상황 | 대응 |
|---|---|
| 자막이 없다 | 멈추고 알린다 |
